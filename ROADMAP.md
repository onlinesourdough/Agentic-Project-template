# Roadmap

## Public preview: 0.1

- Four documented product profiles.
- Safe template applicator.
- Live GitHub Pages reference application.
- Cloudflare-native dogfooding case study.
- Public CI, contribution, security, and release practices.

## Adoption: 0.2

- Feedback-driven profile refinements.
- More real-world case studies and cost baselines.
- Update and uninstall support for files recorded in `.app-template.json`.
- Optional machine-readable profile validation.

## Product layer: later

Commercial products remain separate from the MIT core:

- guided implementation material in Online Sourdough Resources
- maintained production-readiness and conformance checks
- agent and workflow packs
- done-with-you adoption through Inner Circle
- done-for-you delivery through Arc'IT

No paid layer should make the free core unsafe or intentionally incomplete.
